# Obito OS

It is An interactive, web-based desktop environment inspired by Obito Uchiha, built purely in my rework on the code from previous rejection. It features custom windows, a functional terminal, and a touch of the *Naruto* universe.

---

### Features

 **Desktop Environment:** A top bar with a live clock and a custom logo that re-opens the welcome window.

**Obito Logs :** A sidebar app to read through key thoughts and lore entries.

**Uchiha Lore :** An interactive quote generator cycling through classic quotes with a next button.

**Music Player:** A built-in audio player for background tracks.

**Interactive Terminal:** Fully functional command-line interface supporting commands like `help`, `lore`, `date`, `sharingan`, `creator`, and `clear`.

**Customization & Vibe:**
Switch between different custom wallpapers.


 Toggle **Sharingan Mode** to apply a dynamic red filter across the entire OS.

Spawn draggable sticky notes right onto your desktop.



**Draggable Windows:** Fully movable windows complete with z-index stacking so the active window always comes to the front.



---

### Tech Stack
**HTML5** for structure


**CSS3** (custom styles, animations, and media queries for responsiveness)

**Vanilla JavaScript** (window dragging logic, custom terminal interpreter, clock, and state management)



---

### Quick Start

Just clone or download the repository and open `index.html` in any modern web browser, or check it out live!
