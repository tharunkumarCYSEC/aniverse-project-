# Aniverse OS  - Obito Uchiha Edition

A personal anime-aesthetic WebOS built by someone who spends way too much time staring at custom themes and grinding for tech gear. 

This project is a custom browser-based OS packed with utility tools, interactive windows, and heavy Obito Uchiha / Naruto lore vibes. It features draggable custom windows, a functional terminal, live notes, sticky notes, and a vibe switcher because normal mode is boring.

---

## Features

* **Glassmorphism Window Manager:** Draggable windows with smooth layering (`z-index` stacking) and clean taskbar integration.
* **Obito Logs (Notes App):** Interactive sidebar loader for deep-dive thoughts and lore notes.
* **Uchiha Lore & Quotes:** Clickable quote cycler featuring iconic lines from the clan.
* **Obito Theme Audio:** Custom media player for background tracks (`song.mp3`).
* **Interactive Terminal (`obito_term.exe`):** Fully functional mini CLI supporting commands like `help`, `lore`, `clear`, and `creator`.
* **Dynamic Sticky Notes:** Spawn, drag, and write notes anywhere on your desktop on the fly.
* **Vibe Switcher & Wallpapers:** Quick toggle buttons in the top bar to cycle through custom dark wallpapers and an inverted color mode ("Inverted Mode").
* **Live System Time:** Real-time clock display.

## Quick Look / How to Run

It's a pure vanilla HTML, CSS, and JavaScript project—no bloated frameworks or complex build steps required. 

Just clone the repo, open `index.html` in your favorite browser, and click around. Honestly, it's way more fun to just click every button and break things yourself than reading a manual. Enjoy! :]
