I made a web os themed around obito uchiha using just html, css, and vanilla js.
I built it from scratch without any heavy libraries so i could actually understand how everything works. 
You can drag the windows around the screen, click through some uchiha quotes, play music with the spotify embed, drop custom sticky notes wherever you want, and flip a color filter for a sharingan theme mode.
I just wanted something clean and simple that runs right in the browser.
