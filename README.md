## 🌟 About The Project

**Aniverse OS** is an interactive, browser-based mock operating system built from scratch using vanilla HTML, CSS, and JavaScript. Designed with a personal anime theme, this project features fully operational window management, desktop app shortcuts, dynamic sidebars, live clocks, and interactive mini-apps.

---

## 🚀 Features

*   **🖥️ Desktop Workspace**: A custom-themed desktop environment complete with wallpaper styling and a persistent top bar.
*   **⏰ Live Clock**: Real-time date and time tracker built directly into the top bar.
*   **🪟 Interactive Window Manager**:
    *   **Draggable Windows**: Grab any window by its title bar header and move it smoothly across the desktop.
    *   **Z-Index Stacking**: Click on any window or open a new app, and it dynamically rises to the top layer.
    *   **Close & Open Controls**: Functional close buttons and desktop icon triggers to minimize/close and open app windows.
*   **📂 Obito Logs (Notes App)**: A dynamic notes viewer backed by a JavaScript array, featuring a scrollable sidebar and interactive content sections.
*   **👁️ Uchiha Lore (Advanced Quotes App)**: An interactive application where users can cycle through iconic character quotes at the click of a button.

---

## 🛠️ Built With

*   **HTML5** — Document structure and semantic layout.
*   **CSS3** — Custom styling, glassmorphism (`backdrop-filter`), flexbox layouts, and theme shadows.
*   **JavaScript (ES6)** — Dynamic DOM manipulation, window dragging logic, z-index state management, and event handling.
